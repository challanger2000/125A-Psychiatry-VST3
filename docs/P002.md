# P002 — First genuine Windows VST3 host wrapper

**Stage:** Windows VST3 built and Steinberg API validator **47/47 PASS** on commit `7648a57928fbefb31e052d0f581429effa82d8d7` ([Actions run](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45189637433)). **Not a finished product or user-approved audio effect.**

## Implemented in source
- VST3 `AudioEffect` / `EditControllerEx1` using official Steinberg SDK 3.8.1 (pinned source commit `3cdf9ca5d1f5b1b21e0a86832aa4abe55607bd96`; SDK is downloaded in CI, **not bundled in this repository**).
- `PARANOIA` macro linked to P001 reverse-feedback audio DSP, `THERAPY` inverted global Dry/Wet, standard automatable `Bypass`. Other macro IDs are **reserved but not advertised** because they have no DSP yet.
- VST3 process 32-bit float support, mono and stereo arrangements, output buffer copying, in-place support and ongoing delay tails.
- Reads actual automation points and handles changes at block offsets; smoothing remains in the P001 core.
- A versioned serialized state with magic/version and three values: PARANOIA, THERAPY, Bypass. Controller restores the same state for host generic parameters.
- No custom GUI at this stage. The host's **generic parameter UI** is intended for engineering tests.

## Windows CI
Workflow `.github/workflows/windows-vst3.yml` checks out the pinned Steinberg VST3 SDK with recursive submodules, configures Visual Studio 2022 x64, builds the VST3 and stages a temporary build artifact **only on success**.

The official SDK build runs the **Steinberg VST3 validator automatically**; the latest audited build passed 47/47. This is **not a Studio Pro listening test** and does not prove sound quality.

## Build locally (Windows with MSVC 2022 and CMake)
```powershell
git clone --no-checkout https://github.com/steinbergmedia/vst3sdk.git external/vst3sdk
git -C external/vst3sdk checkout 3cdf9ca5d1f5b1b21e0a86832aa4abe55607bd96
git -C external/vst3sdk submodule update --init --recursive
cmake -S . -B build-vst3 -G "Visual Studio 17 2022" -A x64 -DPSYCHIATRY_BUILD_VST3=ON -DSMTG_CREATE_PLUGIN_LINK=OFF
cmake --build build-vst3 --config Release --target PsychiatryPrototype --parallel 4
```
