# P003 — Two new compound-effect worlds and real VST3 integration

## Status
**Three DSP macros wired to a genuine Windows x64 VST3**: DEPRESSION, PARANOIA and OBSESSION. Steinberg API validator **47/47 PASS** at tested source commit `717941a00e9d98cde9c63e6baaf237d7e83695ad`. Sample listening and final Studio Pro verification still required.

## DEPRESSION / DEPRESSION
- Sidechain-style program-dependent compression and harmonic saturation.
- Envelope/darkness-modulated low-pass tone shaping.
- Four delay-network branches per stereo channel with orthogonal Hadamard-style scattering, damped recurrence and saturating reverb return. Sends and reverb contribution rise nonlinearly as macro turns up.
- 0% returns exact dry; 20% introduces coloration; 80% develops distinctive degrading, suffocating sound plus tail.
- Not a literal faithful hardware plate algorithm; a **character effect**, pending listening critique.

## OBSESSION / ZWANG
- Continuous input history in a bounded ring. Macro morphs micro-loop sizes from ~275ms toward ~18ms, with repeated capture, finite gate envelopes and deliberate growing low-bit-depth degradation.
- Fade ramps limit loop-boundary clicks; macro controls both repeat texture and strength.
- 0% is dry; higher amounts produce rigid rhythmic fixation and active degradation.
- Current loops are free-running and **not yet DAW-tempo synced**. Host timeline synchronisation is a separate requirement.

## Global integration and recall
- First three worlds are serial: DEPRESSION → PARANOIA → OBSESSION. Therapy mixes dry and all processed audio **once**, not separately per macro. In-place/out-of-place host buffers are preserved via preallocated scratch.
- P003 state format v2: `magic,version,depression,paranoia,obsession,therapy,bypass`. P002 state format v1 is accepted and maps added knobs to zero. Stable VST3 class IDs and existing parameter IDs.
- Generic host controls only. **Six future macros remain hidden**, not fake knobs.
- Runtime allocation restricted to setupProcessing/prepare, never `process`, but quantitative audio-thread allocation monitoring is outstanding.

## Unit/regression evidence
`tests/test_dark_macros.cpp` validates finite output at 44.1/96/192k, dry bit-exact zero, intensity differentiation, deterministic block-size independence, reverb tail, loop retriggers. Tests operate in Release mode without disabled assert.
CI also generates optional synthetic dry/wet WAV probes with `tools/render_dark_macros.cpp` for DEPRESSION, OBSESSION and the 3-chain combination. **Synthetic WAV probes do not prove musical quality**.
