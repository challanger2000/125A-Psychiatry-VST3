# P005 — All nine independent audio worlds: engineering state

**Code:** [source tree](../src) and [VST3 wrapper](../vst3).
**Audit:** [Windows VST3 CI](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45198889548) (47/47 Steinberg validator PASS) and [DSP CI](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45198889541) (Windows/Linux 5/5 CTest groups PASS).

## New worlds
| World | Multi-DSP path | Caveat |
|---|---|---|
| SCHIZOPHRENIA | Two opposing-grain playback-rate voices, spectral/formant color and cross-modulation; stereo offsets | Grain interpolator and phase alignment require critical artifact listening. Not a medical symptom model. |
| DISSOCIATION | Captured reverse-memory grains, cross-domain filtered smear and frozen echoes; responsive to source | Freeze is granular/time-domain, not an FFT spectral freeze. |
| HALLUCINATION | 17-tap Hilbert FIR approximation with continuously varying frequency shift, formant bands and bounded feedback echo | 17-tap FIR has limited passband rejection; phasing/artifacts must be tested on real sounds. |

P004 also added MANIA, PANIC and PSYCHOSIS with independent algorithms; P003 established DEPRESSION, PARANOIA and OBSESSION. There is **no off-the-shelf plugin code, algorithm code or historical imagery copied from Freakshow Industries**.

## Macro topology and project state
- Nine real C++ engines, each parameter 0 to 1 and 0 = neutral.
- P005 fixed processing order is **DEPRESSION → SCHIZOPHRENIA → MANIA → PANIC → PARANOIA → DISSOCIATION → OBSESSION → HALLUCINATION → PSYCHOSIS**, with a single original signal scratch and one global inverse THERAPY crossfade at the end.
- All nine are exposed as DAW-automatable VST3 parameters; no inert host knobs.
- VST3 host state format **v4**: `magic, version, depression, paranoia, schizophrenia, mania, panic, dissociation, obsession, hallucination, psychosis, therapy, bypass`. Earlier **v1, v2, v3** saved formats are parsed and absent controls default to zero. Stable component/controller UUIDs and existing ParamIDs are unchanged.
- **No custom GUI yet:** generic host UI only. Randomize and language switching remain unimplemented.

## Verification
- `tests/test_paranoia.cpp`: reverse events, dry exactness, input triggering, transport-derived periods, block invariance, finite output.
- `tests/test_dark_macros.cpp`: DEPRESSION and OBSESSION audible-difference thresholds, dark delay reverb decay, retriggers, finite output.
- `tests/test_three_worlds.cpp`: MANIA, PANIC, PSYCHOSIS thresholds and differentiated responses; mono/stereo, rate variations, block invariance, invalid inputs.
- `tests/test_spectral_worlds.cpp`: SCHIZOPHRENIA, DISSOCIATION, HALLUCINATION, differentiated changes, mono/stereo and sample-rate stability, zero-macro exact dry, varied block sizes and invalid inputs.
- `tests/test_full_chain.cpp`: nine-effect simultaneous processing, byte-exact dry at zero, deterministic 137/1024 sample blocks, bounded and finite output, full dry THERAPY reconstruction, silence tail safety, and zero measured callback heap allocations.
- [Nine-world synthetic WAV probes](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45197686369/artifacts/14828402907) provide a basic listening baseline. Generated probes are not musical quality acceptance.
- Original Steinberg SDK 3.8.1 with pinned source checksum/commit. Windows VST3 produced and official validator runs as part of build.
