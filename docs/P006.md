# P006 — Objective FX quality, level and VST3 project-state audit
Date: **2026-11-23** · Version **0.6.0** · **engineering validation only**

## Sources and method
The audio-quality executable `tools/audit_p006.cpp` generates four deterministic **synthetic reference proxies**:
1. Harmonic synth bass, with per-note amplitude decay.
2. Percussive kick/snare/hat-like drum material.
3. Vowel-like synthesized harmonic voice phrases — **not a human vocal recording**.
4. Wide cinematic atmosphere with tones and air/noise.

It processes each source with nine isolated effect worlds **plus all nine combined**, at **20%, 50%, and 85%** macro amounts, with **1.5 seconds at 48 kHz** per case: **4 × 10 × 3 = 120 cases**.

Reported for each case in CSV: dry/wet RMS ratio in dB, wet peak in dBFS, RMS error against dry normalized to dry RMS, DC offset, maximum sample step, render time and time/real-time ratio. Timings are from GitHub Actions runners and **cannot be treated as Windows DAW CPU guarantees**.

**Diagnostic warnings**, not subjective ratings:
- Peak level above 0 dBFS.
- RMS gain above +6 dB (guard against unintended loudness bias).
- RMS gain reduction below −12 dB at 50% or 85%.
- Effect/dry difference below 0.10 at 50% or 85%.
- Weak onset (normalized RMS difference below 0.025) at 20%.

The CI job **fails** for full-scale peaks and >+6 dB unintentional level increases. Warnings also record weak onset, excessive quiet and low difference for later listening review. No audible approval is inferred from these numbers.

## Bugs and fixes, observed on real P006 CI

**Initial audit** showed:
- MANIA at 85% on synth bass: **+9.01 dB RMS** and **+2.27 dBFS peak**.
- MANIA at 85% on synthesized voice: **+10.35 dB RMS**, and on drums about **+9.64 dB RMS**.
- DEPRESSION 20% on synth bass: only **0.0041** normalized RMS difference from dry, with similarly weak onset on other sources.
- PANIC 20% on synth bass: **0.0248**, near the defined weak-onset threshold.
- After the MANIA/onset fixes, PSYCHOSIS at 85% still produced **+8.25 dB RMS** on synthesized voice and **+6.05 dB** on atmosphere (peaks stayed below 0 dBFS).

Implemented changes:
- **MANIA** preserves accelerating pulse/ring/feedback while applying progressively stronger inverse output makeup as drive rises, rather than letting dynamics become volume.
- **DEPRESSION** uses a continuous concave macro curve to make lower values more meaningful without changing 0% and 100% endpoints.
- **PANIC** applies a smooth onset gain curve to its internally coupled transient and noise/tonal gestures.
- **PSYCHOSIS** scales the output after nonlinear band interaction to suppress unintended RMS rise, while preserving a distinct distortion character.
- **HALLUCINATION** Hilbert FIR coefficients now live in a compile-time table, eliminating eight per-sample/per-channel cosine calls. Regression verifies the table against the original formula at floating point precision.

## Project state and API validation
A separate official-SDK test `tests/test_vst3_recall.cpp` instantiates the actual P006 `vst3/processor.cpp` and `vst3/controller.cpp`. It constructs legacy stream layouts v1, v2, v3 and current v4 through Steinberg IBStream, checks restored automatable parameter values and current v4 roundtrip length, and checks malformed/truncated/NaN/future states are rejected. Tests [pass on Windows](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45207296557) (1/1). Steinberg Validator for the actual Windows VST3: **47/47 pass**.

SDK host/API and state stream tests are **not a Studio Pro save/reopen proof**. The final real DAW test remains a release blocker.

## Remaining critical risks
- Sample proxies are not actual guitar, bass, drum and human speech recordings. No level-matched human listening session has been performed. **Qualitative distinctiveness and musical quality have not been approved.**
- PSYCHOSIS wavefolding can alias; the low-pass is not a replacement for proven oversampling. Hilbert frequency shift and grain pitch effects need a high-frequency spectral/artifact audit.
- CPU x-real-time on GitHub runners is not the user's actual plugin load in Studio Pro. Many simultaneous instances, long automation, denormals and all macros at maximum have not been production-certified.
- No custom historical diagnostic monitor or original visual assets have been coded/cleared. No randomization control / DE-EN switch.

**P006 is a passed objective engineering gate, not the completed PSYCHIATRY plugin.**
