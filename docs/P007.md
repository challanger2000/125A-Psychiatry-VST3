# P007 — provisional VSTGUI for eventual musical acceptance

Updated **2026-11-23**. This is a *working code and packaging* checkpoint, **not** a finished GUI.

## Present
- `resource/psychiatry.uidesc`: own original design, 680×550 px dark panel built with Steinberg **VSTGUI 4** classes.
- **Nine equal macro knobs:** DEPRESSION, PARANOIA, SCHIZOPHRENIA, MANIA, PANIC, DISSOCIATION, OBSESSION, HALLUCINATION and PSYCHOSIS. Bound control tags: 100–108.
- **THERAPY** knob (ID 200), inverted global Dry/Wet, with numeric display; **Bypass** switch (ID 999). Control IDs and VST3 class IDs unchanged.
- Parameter readouts are linked to the same host-automatable parameters. The controller returns `VSTGUI::VST3Editor` on `createView(kEditor)`.
- No external images or patient photographs. Color and typography are temporary; LOSS OF CONTROL is shown only as `COMING LATER`, not a nonfunctional action button.
