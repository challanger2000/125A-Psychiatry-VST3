# P008 — 125A PSYCHIATRY v0.8.0, bilingual provisional VSTGUI

Updated: 2026-11-23. Branch: **main only**. Last verified source commit: `a799f56bf1c1697f9b3b27e23fef3d08b246c4e4`.

## Functional front panel

- Dedicated original 680×570 Steinberg VSTGUI layout in `resource/psychiatry.uidesc`; nine equally sized live audio macro knobs and percent readouts, THERAPY (inverse wet/dry), Bypass, LOSS OF CONTROL, EN/DE.
- **LOSS OF CONTROL** is a real momentary `CTextButton` with a private UI tag 9000. `PsychiatryEditor::valueChanged` intercepts the press only, preventing double randomization on release. Controller invokes nine true `beginEdit` / `setParamNormalized` / `performEdit` / `endEdit` calls on ParamIDs 100–108. Grouped start/finish edit support uses Steinberg `IComponentHandler2` when provided.
- Random values: independent 18% chance of 0, otherwise [0.12,0.78]. THERAPY (200) and Bypass (999) are not modified.
- **EN/DE** is a second UI-only tag (9001); the editor exchanges two complete source-defined VSTGUI templates. Controller preference is saved via separate `PSYU` controller state with version 1. The DSP's component state v4 and legacy v1–v3 remain unchanged.
- The GUI uses owned VSTGUI drawing primitives; no external licensed patient/clinic photographs in this prototype.
