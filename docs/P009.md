# P009 — Original reactive monochrome clinical CRT

**Verified on 2026-11-23.** VST3 product factory version **0.9.0**. Latest tested source commit **`4473273ef9006d2800b11f89ac9f3092c9aa265c`**, `main` only.

## Architecture

The temporary 125A PSYCHIATRY front panel has been expanded to **1004×570** and includes a 288×325 pixel monitor. The screen is a **custom VSTGUI `CView`** created by an editor delegate on the GUI thread; there are no external players, window processes, threads, photographs or file dependencies.

Every UI idle callback samples the nine actual `Controller::getParamNormalized` macro controls (IDs **100–108**), applies smoothing, and invalidates only its own view. The strongest active macro chooses among nine internally authored scenes:

1. DEPRESSION — empty institutional corridor, darkness and a remote door.
2. PARANOIA — observation/surveillance field and shifting gaze.
3. SCHIZOPHRENIA — two offset medical scan impressions; fictional effect label, not a symptom simulation.
4. MANIA — accelerating vertical activity meter.
5. PANIC — jagged electrical examination trace.
6. DISSOCIATION — vacant isolation room and displaced outlines.
7. OBSESSION — repetitive diagnostic records and ticks.
8. HALLUCINATION — shadow echoes and spectral after-images.
9. PSYCHOSIS — fragmented analog signal.

Non-dominant active effect values contribute signal interference. An **intensity bar** maps the dominant parameter to a conspicuous black/white CRT fill in every scene; added after a real UI-click test found the DEPRESSION scene otherwise changed too subtly.

The CRT is **true grayscale**, not colored; only the surrounding functional knob labels and controls use the original warm 125A accent. The DE/EN GUI templates and dynamic scene names are bilingual. The original project-specific sound engines are completely unchanged.

**Important:** The CRT follows the actual **macro parameters**, not microphone/audio amplitudes, MIDI pitch or FFT data. There is **no stored historical photography** yet. No clinical patient data or unauthorized patient photographs are used.

## Reduced-motion and persistence

The MONITOR_MOTION control is a private UI tag **9002**, not a host-automatable audio parameter. Motion is **OFF by default** (safe stationary monitor, updated when effect values change). Users can enable slow movement; no hard strobe/full-screen flashing. Preference plus language reside in **controller-only UI state `PSYU` v2**, with previous v1 controller state still accepted; older empty state defaults to EN and static monitor. Actual audio processor state is unchanged **v4**, and all earlier v1/v2/v3 audio state decode tests remain.

## Open release blockers

The visual panel is **functionally tested but historically incomplete**. We still need original or clearly redistributable archival-style imagery/scene library, historically grounded design materials, UI accessibility beyond the motion toggle, and final fidelity and user feedback. This is **not** proof that user Studio Pro loads/stores/automates correctly; that final test is deferred. CPU/aliasing and critical listening on actual guitar, bass, drums, voice and cinematic sources also remain.

**Do not ask the user to test a generic host UI**; the functional P009 front panel is the baseline for eventual end-user acceptance. Do not call P009 a finished release.
