# P012 — VST3 measured aliasing, real 2× PSYCHOSIS oversampling and CPU

Date: **2026-11-23** · Factory version: **0.9.2** · Only branch: **`main`**.
Latest Windows-verified code: **`6e2acf37498ac3fc3c759e9c8501253d078d9212`**.

## Intent and scope

After P010/P011 proved all nine macro controls altered genuine **VST3-processed** audio and that the **0%=Dry / 100%=Wet** endpoints and inverted THERAPY were correct, P012 measured whether the nonlinear worlds generated aliasing, and how much the full chain costs on an instrumented Windows CI runner.

**This is not a subjective quality or full-spectrum certification.** It is an explicitly defined high-frequency stress probe with a clean sine, a negative Dry control, and a numerical folded-harmonic comparison. No actual recorded bass/guitar/speech has been auditioned.

## Measurement: actual Windows VST3, not mocked DSP

The original executable `tests/test_vst3_audio_path.cpp` still instantiates the **actual `Processor` class**, creates Steinberg `ProcessData` input/output stereo buffers at **48,000 Hz, 32-bit float, 256-sample blocks**, sends deterministic signals through `Processor::process`, and verifies v4 component state and parameter automation at sample offset 128. P012 adds:

1. 14,000-Hz or 15,000-Hz source sine at amplitude 0.35, each with exactly 48,000 measurement samples after 0.25 seconds of effect warm-up. At 48 kHz their third harmonic mathematically folds to **6 kHz** or **3 kHz**, respectively.
2. A coherent sine/cosine correlation at the original frequency and the folded frequency, yielding the folded-frequency amplitude in **dBc relative to the processed fundamental**. Dry is the negative control and must have no corresponding spurious folded tone (tolerance below −66 dBc).
3. Test modes: **Dry, DEPRESSION, MANIA, PANIC and PSYCHOSIS**, with one macro 100% and THERAPY 0%. Other effects are not certified by this one-frequency probe.
4. Independent **full-chain CPU probe**: all nine macros at 0%, 85% and 100%; 60,000 stereo samples (1.25 seconds), measuring wall-clock render time, ratio to realtime, max callback duration and output peak on each CI machine. This is **not an absolute CPU utilization percentage**.
5. All original 180 metrology rows, full-Wet direct DSP equivalence, exact 0% Dry, inverse THERAPY, pure-gain placebo negative test, reference level guards, and Steinberg validator remain mandatory.

## Audio DSP implementation

Files: `src/three_worlds.hpp`, `src/three_worlds.cpp`.

The PSYCHOSIS engine previously filtered its nonlinear signal using a modest single-pole output smoothing stage. Harmonics generated before this filter were already above the 48-kHz Nyquist limit and folded into audible low-frequency tones. A single output lowpass running at the host sample rate cannot remove energy after it has already folded.

Now the **processed band signal** is **upsampled to 2× host rate**, reconstructing low, mid and high paths separately with three biquad second-order sections of a **6th-order Butterworth IIR lowpass**. The complete nonlinear band shaping/folding/intermodulation runs at 2×. An independent equally designed six-pole IIR lowpass filters the combined transformed result **before every 2:1 decimation**, so generated high harmonics can be rejected before they fold into the base-rate spectrum.

- Normalized reconstruction cutoff: **0.205 cycles per oversample**, about **0.41× the host sample rate** (19.68 kHz at 48 kHz host).
- Q values of the second-order sections: **0.517638**, **0.707107**, **1.931852**.
- Coefficients computed in `prepare()`; **fixed-size biquad state** inside each plugin instance; no audio callback heap allocation, locks, thread creation, or dynamic oversampling allocation.
- PSYCHOSIS wet output retains the preexisting macro-dependent gain compensation; at 0% the host output remains **bit-identical Dry**, and at 100% it matches the standalone engine's full Wet signal (not a hidden Dry mix).
- **No change** to THERAPY mixer, stable VST3 class/ParamIDs, component project state v4 or EN/DE UI controller state.

## Explicit remaining NO-GO items

- **MANIA and DEPRESSION** still have conspicuous third-harmonic alias energy in the 15-kHz/3-kHz probe, about −20 dBc. PSYCHOSIS also needs **multi-tone and 44.1/96-kHz checks** before final anti-alias approval.
- **Phase/group delay and transient effects** of the added two IIR reconstruction paths need proper measurement and level-matched audible approval. No assertion is made that the added filter is phase-transparent or has zero latency.
- No actual recorded guitar, bass, speech or drum library is used for this narrowband audit; synthetic 14/15-kHz tones are test stimuli.
- Runner CPU performance is not a Studio Pro x64 450-W PC guarantee; long-session many instances/denormals/automation and true-peak robustness need independent QA.
- No finished historic photographic CRT/clinic styling or real Studio Pro project save/reopen sign-off.

**User testing is not requested yet.** [STATUS](../STATUS.md) is the authoritative latest version and Actions evidence; continue on **main only**.
