# P014 — PANIC anti-aliasing verified on the actual Windows VST3

**2026-11-23**. Main branch only. **Version: 0.9.4**. Latest source commit verified by CI: `0fdf15bc45e1acc86b74653423709fd99004d9f6`. Engineering checkpoint; **not a finished VST3**.

## Objective and exact source of the evidence

[P013](P013.md) demonstrated that PSYCHOSIS, MANIA and DEPRESSION had much lower high-frequency aliasing after 2× filtered nonlinear processing. **PANIC remained at −31.87 dBc in a 15-kHz sine/3-kHz third-harmonic folding test at 48 kHz**. A loudness change cannot remove that frequency-domain artifact, so P014 alters only the wet shaper.

`src/three_worlds.hpp`: PANIC channel state now owns an independent `detail::Oversample2x` object. `Panic::prepare` initializes filters; `reset` explicitly clears runtime states but preserves already computed Butterworth coefficients. `Panic::process` sums normal host-rate excitation (`x*(1 + 0.25*m) + 0.85*m*pulse + 0.4*m*piercing`) then sends it through **filtered 2× interpolation → tanh → independent anti-alias lowpass → downsampling**. The preexisting wet-only output trim and tremor modulation remain. No additional original/Dry signal is added. Processing remains allocation-free.

The fixed sixth-order Butterworth filter Q values and normalized cutoff are the same as the already verified [P013 oversampler](../src/oversample2x.hpp), around **0.205 cycles per oversampled sample**, so filter cutoff adapts to host sample rate. **This does not imply every possible alias is eliminated.**

## Measured before/after (real `Processor::process`, not mocked)

Input is a 0.35-amplitude sine, 60,000 stereo frames at 48,000 Hz; the first 12,000 samples are discarded. Compare a processed-tone fundamental against the exact expected third-harmonic folded frequency by coherent sine/cosine projection.

| PANIC 100%, THERAPY 0% | P013 reference | P014 actual Windows VST3 | Relative improvement |
|---|---:|---:|---:|
| **15,000 Hz input → 3,000 Hz fold** | −31.87 dBc | **−69.35 dBc** | **37.48 dB** |
| **14,000 Hz input → 6,000 Hz fold** | −31.86 dBc | **−73.41 dBc** | **41.55 dB** |

The new automated P014 gate **fails if PANIC exceeds −45 dBc** on either defined stress tone. P013 MANIA and DEPRESSION gates remain **−50 dBc**, and P012 PSYCHOSIS remains **−45 dBc**. The measured negative Dry control contains no material third-harmonic fold.

## Unfinished requirements and no-go boundaries

1. **No end-to-end spectral alias certification.** Only two input tones at 48 kHz and their exact third-harmonic foldback are covered. Full 44.1/48/96-kHz multi-tone and nonlinear intermodulation spectrum is not yet measured; other five macros have not passed equivalent alias-specific gates.
2. A sixth-order IIR oversampler introduces **group delay and phase response**, which may matter for transient attacks and partially wet mix values. Need measure and compare; exact 0% dry identity does not prove intermediate wet/dry mixes are phase-neutral.
3. No genuine recorded bass, drum, guitar, voice or atmospheric material has been critically auditioned. Synthetic test signals are not a substitute for musical judgment.
4. A 0.0691× realtime render on a GitHub Windows runner is **not** a CPU guarantee for Studio Pro with many instances or demanding audio buffers. Long-session and denormal testing remains.
5. Historical photo assets/fully finished clinic hardware GUI, copyright provenance and final Studio Pro save/reopen/user acceptance remain unfinished.

**No request for user testing** at this engineering stage. Continue exclusively on `main` and keep [STATUS.md](../STATUS.md) synchronized.
