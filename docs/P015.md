## Measurement and acceptance design

The existing actual VST3 audio harness now supports a supplied host sample rate and buffer count instead of always using 48 kHz / 60,000 frames. A 14+15-kHz sine pair at combined ±0.35 peak is processed at **44.1 / 48 / 96 kHz** for all **nine** macros with actual `psychiatry::vst3::Processor::process`. Each host rate checks (1) individual macro 0%=bit-identical Dry, (2) each macro at 100% and THERAPY=100%=bit-identical Dry, and (3) 100%-Wet output finite and without >4.0 sample magnitude. It also measures four third-order spectral lines for four nonlinear worlds.

The products `3×14k=42k`, `3×15k=45k`, `2×14k+15k=43k`, `2×15k+14k=44k` are folded at 44.1/48 kHz and remain **unfolded in-band harmonics/intermodulation** at 96 kHz. Measurements use one exact second after 12,000 warmup samples, avoiding spectral-bin leakage. An exact-input negative control verifies that the generated two-tone input itself has no alias spur.

Expected output: `P015_multirate_intermod_metrics.csv` with 27 per-macro/rate peak rows plus 48 spectral rows (**75 total**), alongside P012/P013/P014 single-tone guards, existing P010 180-row comparisons, official Steinberg validator, GUI and standalone DSP workflows.

Spectral numbers from this new stimulus are **observations**, not predetermined alias limits. Do not claim full anti-alias clearance or real-listening acceptance on the strength of this probe. Follow up with evidence-derived guards and phase/transient measurements.
