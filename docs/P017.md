# P017 — exact endpoints after live VST3 automation

Factory **0.9.6**, main, tested `79fa77c297933b31cb5b81acefa5ad9d4a3345bf`; [Windows VST3](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45293157519) and [Windows/Linux DSP](https://github.com/challanger2000/125A-Psychiatry-VST3/actions/runs/45293157516) **SUCCESS**. Logs confirm all 54 cases, 47/47 validator and 45/45 full-Wet matches.

All nine macro smoothing paths and the VST3 THERAPY smoothing path share a bounded endpoint rule. The prior exponential recurrence approached zero asymptotically and could stall near full scale due to float precision, making a 0% automated parameter differ from a 0% loaded state. P017 keeps exponential smoothing and snaps only at exact endpoint targets within 1e-5 or when float arithmetic stops advancing. Intermediate targets and settled effect algorithms are unchanged.

The actual Processor test starts each effect at 100%, sends a host automation point at a non-aligned sample offset, and verifies exact raw float output after 0.5 s of settling. This is repeated for all nine macros, macro 0% and inverse THERAPY 100%, at 44.1/48/96 kHz (54 cases). Tiny finite floats and ±20 headroom samples must survive unchanged. Wet activity before the event is required. Existing P010–P016 gates are retained.

Phase cancellation found in P016 is not fixed by this change. A matched-latency oversampling redesign would require consistent delay compensation for each wet/dry branch, the complete chain and native bypass. Changing the Dry phase only at intermediate mix positions would violate the existing exact half-sum contract and is not a valid shortcut. Do not label phase or listening acceptance complete.
