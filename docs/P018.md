# P018 — phase-aligned oversampling

The v0.9.6 P017 production DSP has a measured phase cancellation problem (P016). The replacement kernel is a 49-tap symmetric halfband FIR with exact 24-sample host-rate latency for a complete 2x interpolation/decimation pair, 12 symmetric coefficient pairs and exact unity DC. Fixed-size per-instance state; no allocation in process. Design: Parks–McClellan lowpass, normalized oversampled pass edge .195, stop edge .305, even coefficients zero except center .5, odd coefficient pairs normalized to sum .25. The standalone C++17 GCC probe measured symmetric impulse, DC .999999996, 18 compensated phase points with magnitude deviation <.002 dB, and tanh 14/15-kHz folded aliases −95.12 to −105.22 dBc at 44.1/48 kHz. These are local kernel results, not actual plugin acceptance.

Integration must align each of the four nonlinear stages' Dry/Wet paths, report constant total latency to the host, preserve all neutral and Bypass samples exactly after compensation, retain prior automation and alias checks, and remeasure real full-effect cancellation and transient/CPU. No fixed delay should be silently inserted without PDC. No user test yet.
