# P020 — immutable OBSESSION stutter and wet-only boundaries

The old loop used a 0.7 s live ring, while a captured repeat group could outlive it. It also chose the first grain from zero-filled history, and faded the entire wet amount, leaking live input at every edge even at macro 100%. The fixed 96-sample fade changed duration with host rate.

P020 waits for a complete captured grain, freezes repeat count and grain length together at capture, bounds repeat count against 1.5 s of preallocated ring memory, and applies a 2 ms fade to the processed loop rather than the mixer. The wet endpoint returns the actual loop directly, including its intentional gated edges. A small 0.54 dB full-wet trim preserves headroom without injecting dry input. Zero macro remains exact dry.

Local C++17 tests: 44.1/48/96 kHz immutable full-wet loop despite subsequent input sign reversal, 17/509-sample block equivalence, real replay and zero startup; full-wet source proxy gains +1.357, +5.207, -1.092, +0.651, +1.531 dB respectively for synth bass, drums, guitar, voice-like and atmosphere. Not whole-VST3 verification. New standalone long-history/partial-mix and real processor 3-rate wet-loop regression. CI pending. No user testing.
