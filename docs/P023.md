# P023 — host tail declaration and decay

The pinned SDK AudioEffect default getTailSamples() is kNoTail; that is incorrect for the existing serial reverb/grain/echo chain, and a host may truncate sound during offline rendering or playback optimization. Candidate reports a fixed conservative 30 seconds plus 96 samples at the active sample rate, without changing DSP or state IDs. No per-edit tail renegotiation.

New actual processor audit at 44.1/48/96 kHz: one second initial silence, two seconds of source signal, then the full reported tail. All nine macros 100%, global THERAPY 0. Input silence flags set on whole silent buffers. Log peak/RMS for each second; require exact initial silence, audible source/tail, bounded finite output, and last full second plus final latency under -100 dBFS. The chosen bound is a candidate until measured; if the tail does not converge investigate the responsible stage rather than truncate artificially. CI pending. No Studio Pro sign-off.
