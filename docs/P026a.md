# P026a — PANIC / PSYCHOSIS implementation candidate

Design authority: [P026](P026-SOUND-DESIGN.md). Baseline v0.9.12 P024 eedbb5ca9bef415bd40e96044f4a4a921bfa0a2d, P025 recorded-source QA. The owner rejected the birdlike PANIC and weak PSYCHOSIS. No GUI, parameter IDs, global macro curves, other seven engines, THERAPY or LOSS OF CONTROL changes.

PANIC uses stereo-linked onset detection and irregular sustain events, with three gestures (interruption, variable causal delay, backwards read), attack/release windows, and source-derived bandpass edge excitation. No independent tone/noise generator. History allocated in prepare, bounded to .21 s at host rate. Existing 24-sample fixed delay and 2x nonlinear stage retained. Timings and depths are initial design settings, not measured optima.

PSYCHOSIS uses complementary frequency split, independently driven bass, asymmetric clipping, true continuous multi-fold triangular transfer, inter-band multiplication, midrange emphasis and gently driven upper band. Bounded slow envelope drive reference, DC rejection and peak control; no bitcrushing/sample-rate reduction. Existing 2x FIR architecture and 24-sample stage latency retained. This is a candidate, not a proven musical improvement. Strong nonlinearities require verification of foldback, level, phase, and multi-rate behavior; preserve prior gates and address any failures rather than waive them.

Added standalone sustained 55 Hz shock/event and distortion harmonic/bass-retention regression with silence and stereo identity. Existing test suite remains. Windows and recorded comparison evidence pending. No user test requested until all twelve worlds and visual redesign are ready.
