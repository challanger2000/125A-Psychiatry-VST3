# P026c — PARANOIA acoustic layer candidate

Owner-approved optional acoustic extension from P026. First world: PARANOIA. Six genuine pinned recordings (two whispered textures, knocking, two metal footsteps and creak), retained unmodified in sound-library. Select and decode up to 5 seconds, trim silence, normalize conservatively, fade, convert to immutable PCM16 mono at 24k during build. Source Git blob SHA1 and CC BY 4.0 verified before decoding. Runtime is original C++ with no decoder or heap. The layer uses short variable excerpts, weighted whisper selection, no consecutive same clip, irregular gaps and varied stereo position. It is blended into the actual PARANOIA wet and cross-feedback paths with input-envelope-dependent gain, then controlled by the existing macro and global THERAPY. No autonomous output at initial silence. Playback disabled below 32 kHz because of source-rate/Nyquist limit; existing DSP remains available there. No change to parameter IDs, GUI, state v4 or PSYCHOSIS distortion-first policy. Exact 0/100 endpoints remain governed by existing routes.

P026b alias correction preserved. Six selected sources are candidates, not auditioned approval. The other 17 archived sounds remain available for other worlds. Source-player tests assert actual nonzero energy, stereo variation, multiple events, exact silence/zero, deterministic reset at 44.1/48/96k. Existing macro, host, gain, CPU, alias, state and tail tests remain unchanged. Build-time decoder installed only in development CI. Windows actual VST3 source-layer audio verification, recorded A/B and human musical assessment are pending. Do not call v0.9.13 final.
