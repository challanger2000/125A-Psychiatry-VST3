# P026i — MANIA sound design / v0.9.17 candidate

The previous MANIA was amplitude/ring modulation and feedback saturation, not genuine source retrigger. Keep its useful nonlinear chopper but make the rhythm source-derived. No new control or external sound layer is required for this candidate.

- Stereo-linked clock 2.6–24 Hz with onset-dependent acceleration at intermediate amount.
- Two-pole 1.8 kHz lowpass history, 90 ms capacity per channel allocated only during prepare. At a pulse, capture a recent 14–26 ms fragment (capped at 42% of the current pulse period), repeat it twice, tapered edges. The read region is not overwritten during playback: maximum age is three fragment lengths (78 ms < 90 ms).
- Blend the repeated low-band fragment against current low-band content; retain high-band live excitation. Moving TPT state-variable bandpass (330–2800 Hz at normal rates, capped relative to sample rate), Q 0.8–2.0, bounded contribution. No random gaps, no sample rate reduction or bitcrushing.
- Preserve existing 2x linear-phase nonlinear feedback, ring/chopper and gain correction. Fixed 24-sample stage / 96-sample chain latency unchanged. Exact 0% and THERAPY dry remain required. No new parameter, state format or GUI.
- Preflight: isolated C++17 retrigger core compiled and executed at 1, 44.1, 48, 96, 192 and 2000 kHz. 2-second counts at 30/70/100%: 9/26/47–48. Source stops at first capture: RMS 0.10161–0.12274 at 15–22 ms after cutoff, demonstrating replay rather than amplitude modulation alone. Identical stereo output on identical input; finite bounded samples.
- Separate isolated C++ model combining the retrigger, existing FIR coefficients and existing chopper/feedback measured 48 kHz single-tone foldback -96.84/-108.61 dBc and worst monitored 44.1/48 kHz two-tone product -74.12 dB input-referenced; worst cancellation on the multitone phase probe -0.47 dB. These are **not** full repository tests or native Windows/DAW results. Git checkout unavailable in local environment.
- New actual Mania regression checks capture density, mono replay after source stops, true silence and identical stereo, in addition to existing block-size, neutral, no-heap, automation, state, alias, level and full-chain tests. Native Windows VST3, full standalone suite, EditorHost, recorded audio and musical acceptance remain pending. Do not weaken pre-existing thresholds.
