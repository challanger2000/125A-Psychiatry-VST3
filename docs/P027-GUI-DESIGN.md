# P027 — owner-approved visual direction (2026-11-24)

This supersedes older P026 visual palette and diagnostic CRT placeholder directions. DSP-first order still applies. The user wants the look of a fictional vintage psychiatric horror apparatus, not a contemporary plugin with decorative wallpaper.

## Faceplate and controls
- Use the FIRST generated COLOR ceramic tiled wall: dirty ivory white, muted green/brown, cracked grout, water stains, age. The monochrome tile version is not the selected faceplate.
- Twelve same-size genuine raster-rendered black aged Bakelite knobs in a circular ring; realistic fluting, patina, fixed light and shadows, visible pointer. A worn ivory/yellowed circular dial and enamel nameplates. Readable value indications and consistent target sizes.
- Genuine rendered PNG filmstrip (proposed 128 positions), not standard vector-painted knobs. Static dial, mount and cast shadow separated from rotor where practical. A subtle intentionally eccentric/wobbly visual rotation is acceptable; actual control value, pointer relationship, automation and endpoint remain precise.
- Larger ivory THERAPY knob; dark red vintage LOSS OF CONTROL push button. These are concept decisions, not final pixel layout.
- Keep approved clockwise order DEPRESSION, PARANOIA, SCHIZOPHRENIA, MANIA, PANIC, DISSOCIATION, OBSESSION, HALLUCINATION, PSYCHOSIS, DELIRIUM, CATATONIA, AMNESIA. THERAPY 0 wet / 100 dry. Randomize all twelve sound parameters only; preserve THERAPY, bypass, language and motion.

## Central image field
- Circular bull's-eye, changing images tied to actual macro settings. Own generated pictures of imagined historical corridors, rooms, strange old clinical machines, fictional horror characters and details. Strong B/W, aged yellowed archive prints and sepia all welcome; user especially liked the generated portrait. No real patient pictures or copied film characters.
- Full-field motion, when enabled: slow parallax/zoom, double exposures, subtle deformation, shadow movement. No violent rapid flashes, no animation in reduced-motion mode, no DSP callback image work.
- Atmospheric fictional horror, not splatter. Keep text/value legible over textured material. DE/EN controls remain functional.
- The user clarified "echte gerenderte Bilder" after a VSTGUI discussion: primary requirement is raster artwork, not a framework migration. Do not silently rewrite the functioning host adapter or claim a JUCE port has been requested. Keep existing SDK for this project unless a separately confirmed migration is required.
