# 125A PSYCHIATRY P030d – lokaler Performance-Test
Windows x64. ZIP komplett entpacken, Studio Pro und andere rechenintensive Anwendungen schließen, start.bat doppelklicken. Kein Administrator, keine Installation, keine Änderung an Plugin-Ordnern. Das mitgelieferte P030d-Bundle wird direkt geladen; SHA256 der DLL wird vor dem Test geprüft. Die 24 Fälle (44,1/48 kHz, 256/128/64 Samples, eine/vier seriell berechnete Instanzen, repräsentativ/alle zwölf hoch mit dichter Automation) erzeugen je 10 Sekunden Audio nach Warmup. Ausführung kann je nach Rechner länger dauern. Alle Tests laufen auch nach Zeitbudget-Überschreitungen weiter. Nach Abschluss RESULT-* Ordner mit report.txt, measurements.csv, system.txt und exit-code.txt zurückgeben. 0 bedeutet keine Callback-Rechenzeitüberschreitung, 4 bedeutet mindestens eine, sonst Testfehler. CSV enthält Callback-Wallclock, Thread-Zyklen, Startverspätung und synthetische Finish-Deadline getrennt. Das künstliche Scheduling, serielle Mehrinstanzlast und dichte Automation sind nicht identisch mit einer DAW; keine ASIO-Messung, keine Aussage über tatsächliche Dropouts. Finaler Studio-Pro-Test bleibt erforderlich. Produktstand 4828981be7013e8dcba711dce29d97cd7673ad72, v0.9.28. Keine Produktänderung.
